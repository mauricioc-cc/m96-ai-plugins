# Ligação para leads

Oferecer ligação apenas quando uma conversa síncrona puder avançar o atendimento, como pedido explícito de contato, interesse de alta prioridade, pergunta complexa ou necessidade de combinar visita. Não tratar a existência de telefone como autorização para ligar.

## Pedido de autorização

- Sugerir primeiro uma mensagem curta por WhatsApp quando não houver autorização clara para ligação.
- Identificar o corretor e mencionar brevemente o imóvel ou interesse.
- Fazer uma pergunta fácil de responder, como `Posso te ligar agora ou você prefere outro horário?`.
- Quando houver horários reais disponíveis, oferecer no máximo duas opções concretas.
- Não inventar disponibilidade, não pressionar e não afirmar que a ligação já está agendada.
- Entregar a mensagem com o link `Abrir no WhatsApp` conforme `whatsapp.md`.

## Link de telefone

1. Reutilizar somente o telefone validado conforme `whatsapp.md`.
2. Montar `tel:+TELEFONE_INTERNACIONAL`, preservando o `+` e usando apenas dígitos depois dele.
3. Entregar um link Markdown identificado como `Ligar por telefone`.
4. Informar que o link abre o discador comum; não inicia automaticamente uma chamada do WhatsApp nem confirma que o lead aceitou a ligação.
5. Mostrar o link como opção mesmo quando a mensagem de autorização for sugerida, deixando a decisão final com o corretor.
