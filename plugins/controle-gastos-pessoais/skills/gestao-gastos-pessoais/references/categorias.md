# Categorias próprias do usuário

Não impor uma lista padrão. Usar a lista de categorias do controle escolhido e ampliá-la conforme o usuário orientar ou os dados trouxerem evidência suficiente. Registrar o critério de uso e se a definição veio do usuário ou de inferência sustentada pelos dados.

Para cada lançamento:

1. Examinar a descrição e os demais dados disponíveis. Uma categoria presente na fatura ou no extrato é apenas uma sugestão: verificar se faz sentido para aquele gasto.
2. Aplicar uma regra já confirmada pelo usuário quando ela corresponder ao caso, sem extrapolar para compras de natureza diferente no mesmo estabelecimento.
3. Inferir uma categoria apenas quando a descrição e o contexto indicarem concretamente a natureza do gasto. Se for uma nova categoria, incluí-la na lista própria com o critério usado.
4. Se a natureza continuar incerta, perguntar ao usuário antes de gravar o lançamento. Não preencher `Outros`, uma marca de revisão ou uma categoria sugerida pela fonte só para completar a coluna.
5. Quando o usuário corrigir uma categoria, atualizar o lançamento e o critério aplicável. Rever outros lançamentos semelhantes sem recategorizá-los automaticamente quando o contexto puder ser diferente.
