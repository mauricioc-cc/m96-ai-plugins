# controle-gastos-pessoais

Plugin genérico para controle de gastos pessoais com persistência em Google Drive/Google Sheets.

## Estrutura

- `.codex-plugin/plugin.json`: manifesto do plugin
- `skills/gestao-gastos-pessoais/SKILL.md`: fluxo principal
- `skills/gestao-gastos-pessoais/references/modelo-planilha.md`: modelo de dados
- `skills/gestao-gastos-pessoais/references/categorias.md`: taxonomia inicial

O plugin foi desenhado para criar uma planilha por usuário e operar o controle principalmente via conversa, sem exigir edição manual da planilha.
